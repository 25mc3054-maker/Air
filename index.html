How It Works — Model Architecture Specification

1. Domain Feature Branches

Processes 49 temporal inputs across 4 domain-specific causal convolutional streams (Pollution, Meteorology, Atmospheric External, Temporal/Availability).

2. Gated Linear Unit Fusion

Combines branch representations (224 channels) into a unified 256-dimensional non-linear representation vector with feature gating.

3. 4-Head Self-Attention

Dynamically models multi-day temporal dependencies across the 72-hour context window without future temporal leakage.

4. Dual Output Heads

Parallel linear projection for 72-hour regression forecast + auxiliary BCE classification head for PM2.5 spike detection (≥ 345 µg/m³).
